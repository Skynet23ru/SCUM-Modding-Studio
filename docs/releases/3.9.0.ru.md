## SCUM Forge 3.9.0

### Серверные инструменты
- **Консоль.** Логи сервера как они пишутся (движок, чат, админ, входы, убийства), поиск по словам, сообщения игрокам и админ-команды прямо из программы. Режим «Выдать предмет игроку» кладёт предмет под игрока.
- **Панель.** Кто в сети, FPS, активные бункеры, сделки с торговцами, смерти, чат и события. Вкладка **«Действия»**: кто что подобрал, переложил, открыл, собрал. Вкладка **«Машины»** показывает владельцев по замкам. Клик по строке открывает карточку с картой.
- **Серверные моды `StudioBridge` и `StudioActivity`** ставятся на сервер сами (для удалённого сервера только если разрешена запись и UE4SS уже стоит).

### Несколько и удалённые серверы
- В Настройках появился список серверов; активный сервер переключается в строке состояния, все страницы следуют за ним. Сервер может быть на этом ПК или в сетевой папке (`\host\share\SCUM Server`).
- **Удалённые серверы по SFTP, FTPS и FTP** (VPS и игровые хостинги). Файлы зеркалируются на ваш ПК, страницы работают как с локальным сервером. По умолчанию сервер только читается; запись (моды, команды) включается галкой. Ключ хоста (для FTPS отпечаток сертификата) запоминается и проверяется при каждом подключении, пароль хранится зашифрованным для вашей учётной записи Windows.

### Оружие
- У копии оружия можно оставить только магазин-копию, а для магазина выбирать и создавать свои типы патронов (из версии 3.8.0 и далее).
