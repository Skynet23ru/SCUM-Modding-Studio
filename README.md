# SCUM Forge

**Бесплатный редактор карты и создатель модов для SCUM: правьте остров в 3D, стройте мосты и дороги, настраивайте и
клонируйте технику и оружие, наполняйте данжи зомби, охраной и лутом и экспортируйте готовые pak-моды для одиночной игры
и выделенных серверов. Без Unreal Editor.**

> руководство по данжам. Подробнее — в разделе [Происхождение и авторство](#происхождение-и-авторство).

## Что это

SCUM Forge — настольная программа для **модинга SCUM** под Windows. Она напрямую читает «запечённые» (cooked) файлы игры
на Unreal Engine 4.27, показывает карту так, как её рисует игра, и записывает ваши изменения в обычный мод
`pakchunkNNN-<Имя>_P.pak` для клиента и выделенного сервера. Любое действие — это строка в журнале проекта: отменить
можно что угодно, даже после перезапуска, а после обновления игры мод пересобирается заново.

## Быстрый старт

1. Скачайте сборку со страницы [Releases](https://github.com/Skynet23ru/SCUM-Modding-Studio/releases) этого форка (если
   релизов там ещё нет — соберите из исходников, см. ниже) и распакуйте куда угодно. Установка и .NET не нужны.
2. Запустите `ScumStudio.App.exe`. При первом запуске откроется **мастер**:
   - **Язык** — 10 языков, по умолчанию берётся язык системы.
   - **Игра и сервер.** Достаточно указать папку игры и папку сервера (или нажать «Найти в Steam»): остальное программа
     делает сама — находит AES-ключ, проверяет его на ваших файлах и хранит зашифрованным под вашей учётной записью Windows.
   - Затем открывается **Главная** — список того, что уже настроено и что делать дальше.
3. Создайте проект (Проекты → Новый), откройте нужную ячейку на карте и правьте. **Экспорт** собирает мод.
4. Скопируйте `pakchunk…_P.pak` и `.sig` в `SCUM\Content\Paks` (программа умеет делать это сама через папки модов
   в настройках).

Ключ AES — ваш: он никогда не передаётся ИИ-клиентам и не попадает в репозиторий.

| | |
|---|---|
| **3D-редактор карты** | Летайте над всем островом или откройте одну ячейку. Двигайте, вращайте, копируйте, удаляйте и добавляйте объекты, здания, деревья и камни. |
| **Мосты, дороги, стены** | Меню **Shape** изгибает кусок моста, стены или дороги в дугу, удлиняет, расширяет, сваривает и повторяет с рабочей коллизией. |

| **Мастер первого запуска и Главная** | Язык, папка игры, папка сервера; чек-лист «что настроено и что делать дальше». |
| **Левая панель навигации** | Страницы сгруппированы; на узком окне панель сворачивается в значки. |
| **Серверные Lua-моды** | Установка UE4SS на сервер, моды как файлы, Lua-редактор с проверенным каталогом функций, журнал UE4SS. |
| **Редактор лута** | В прямоугольнике карты меняет, что выдаёт пресет лута (группы, шанс, количество, износ) — через официальную JSON-кастомизацию сервера. |
| **Охрана и NPC-посты** | Точки зомби, вооружённые NPC и серверные охранные посты (Lua-мод) для данжей. |
| **Экспорт мода** | Один клик собирает клиентский pak (и серверный) с отчётом `export-report.md`. |
| **10 языков** | English, العربية, Русский, Deutsch, Español, Français, Türkçe, Bosanski/Hrvatski/Srpski, Tiếng Việt, 简体中文. |
| **ИИ-управление** | Claude и другие MCP-клиенты могут править карту, технику, лут и серверные моды. |

## Как это работает

1. **Чтение.** Программа монтирует `.pak` игры (с ключом AES) и читает пакеты через
   [CUE4Parse](https://github.com/FabianFG/CUE4Parse) и собственный побайтовый ридер: уровни, меши, текстуры, материалы,
   блюпринты, тайлы ландшафта.
2. **Правка.** Каждое действие записывается в **проект** — папку `<Имя>.ssproj` с `project.json`, `journal.jsonl` (одна
   правка на строку) и `notes.md`. Отмена и повтор переживают перезапуск; файлы игры не меняются.
3. **Экспорт.** Каждый изменённый уровень пересобирается из **оригинальных** файлов игры плюс журнал. Всё упаковывается в
   `pakchunk900-<Имя>_P.pak` с копией штатного `.sig`.
4. **Игра.** Скопируйте pak и `.sig` в `SCUM\Content\Paks`. После обновления игры откройте проект и экспортируйте снова.

## Сервер: Lua-моды, лут, охрана

Страница **Сервер** состоит из четырёх вкладок: **Моды**, **Lua-редактор**, **Лут**, **Журнал**.

- **UE4SS.** Кнопка «Установить UE4SS» скачивает официальный релиз с GitHub, проверяет его (SHA-256) и ставит рядом с
  `SCUMServer.exe`. Программа **не** запускает и не останавливает сервер; включать и выключать UE4SS нужно при
  остановленном сервере.
- **Моды.** Готовые шаблоны (объявления, приветствие игрока, журнал событий, команда `!time`) или свой код; каждый мод —
  папка с `main.lua`, включается и выключается отдельно.
- **Lua-редактор.** Проверка синтаксиса (MoonSharp, код только разбирается, не выполняется), поиск функций в дампе
  классов вашего сервера и **каталог функций**: что проверено на живом сервере, что только замечено, а что роняет сервер.
- **Лут.** Редактор пишет файлы официальной настройки лута сервера
  (`Saved\Config\WindowsServer\Loot\Spawners\Presets\Override\<Зона>`). После сохранения выполните на сервере
  `#ReloadLootCustomizationsAndResetSpawners`.
- **Охранные посты.** Вооружённые NPC-«энкаунтеры» с карты на выделенном сервере не появляются, поэтому охрана
  делается Lua-модом, который создаёт её во время работы сервера.

Подробности и форматы файлов: [docs/SERVER-MODS.md](docs/SERVER-MODS.md).

## Данжи: пошаговое руководство

Как сделать место на карте с зомби, охраной и лутом, чтобы это работало на выделенном сервере: что за что отвечает,

## ИИ-управление (MCP)

**Настройки → Управление ИИ (MCP-сервер) → Вкл → Копировать команду для Claude Code.** После этого Claude может открывать
уровни, расставлять объекты, править технику и оружие, ставить зомби и охрану, менять лут по зонам, писать серверные
Lua-моды, экспортировать мод и делать скриншоты для самопроверки. Сервер слушает только `127.0.0.1`, требует токен и
никогда не видит ключ AES. Список инструментов и модель безопасности: [docs/MCP.md](docs/MCP.md).

```
claude mcp add --transport http scumstudio http://127.0.0.1:47130/mcp --header "Authorization: Bearer <токен>"
```

## Командная строка

```
scumstudio level list   "D:\SCUM\Content\Paks"
scumstudio item list    "D:\SCUM\Content\Paks" --kind Weapon
scumstudio project new    MyMod.ssproj --source "D:\SCUM\Content\Paks"
scumstudio project export MyMod.ssproj -o out
scumstudio server ...     # серверные моды: установка UE4SS, список и запись Lua-модов
```

CLI читает ключ, сохранённый программой; на другой машине задайте переменную `SCUMSTUDIO_AES_KEY` (в командной строке ключ
не передавайте).

## Сборка из исходников

Нужны: Windows 10/11 x64, .NET 8 SDK, видеокарта с OpenGL 4.3.

```
git clone https://github.com/Skynet23ru/SCUM-Modding-Studio.git
cd SCUM-Modding-Studio
scripts\build.ps1 -Configuration Release -Test      # сборка + тесты (тесты с данными игры сами пропускаются)
dotnet run --project src/ScumStudio.App             # запуск
```

В Visual Studio 2022 откройте `ScumStudio.sln` и сделайте `ScumStudio.App` стартовым проектом. Подробнее:
[docs/BUILDING.md](docs/BUILDING.md).

Имена проектов и пространств имён (`ScumStudio.*`) оставлены прежними намеренно: так изменения оригинала можно подтягивать
в этот форк.

## Вопросы и ответы

**Работает ли это на официальных серверах?** Моды загружаются только там, где сервер их запускает: в вашей одиночной игре,
на вашем выделенном сервере или на серверах сообщества с модами.

**Игра обновилась и мод сломался.** Откройте проект и нажмите **Export mod** ещё раз: каждый экспорт начинается с текущих
файлов игры.

**Ключ не найден.** Вставьте его в поле ключа в мастере: программа проверит его перед сохранением.

**Где мои проекты?** В `Documents\ScumStudio Projects`, если вы не выбрали другую папку.

**Почему в приложении нет проверки обновлений оригинала?** Проверка обновлений смотрит релизы этого форка, а не оригинала.

## Безопасность и честная игра

- Программа только читает файлы игры и пишет pak-моды. Она не трогает запущенную игру, не патчит `SCUM.exe` и
  `SCUMServer.exe`, не подделывает подписи pak (копирует штатный `.sig`) и не содержит читов на скорость, движение и бой.
- Файлов игры, ключей и извлечённых ассетов в репозитории нет.
- Используйте моды на серверах, где они разрешены, и соблюдайте правила игры.
